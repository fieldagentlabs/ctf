# S0-F1 · First Contact

**Surface:** Claude chat · **Points:** 25 · **Time:** about 15 minutes · **Est. API cost:** free (any Claude plan)

## Briefing

Every recruit gets a dossier on day one. Yours looks ordinary: a welcome, some rules, a seal. It isn't. Three code words are hidden in it, each one a different way, and the Directorate wants to know whether you and your agent can find them all.

Your agent reads fast, but it reads what it's pointed at. Finding everything is on you: tell it where to look, then check what it brings back.

## Objectives

1. Download the dossier: [`data/recruit-dossier.pdf`](data/recruit-dossier.pdf).
2. Open [claude.ai](https://claude.ai) (any plan, including free) and upload the dossier.
3. Ask Claude to find the three hidden code words. They're hidden three different ways.
4. Check each word against the dossier yourself before you trust it.
5. Submit the words in the order they appear in the dossier, as `FA{WORD1-WORD2-WORD3}`. Capitals or lowercase both work.

## What you're practicing

- Uploading a file to Claude and asking about all of it, not just the obvious text
- Telling Claude what kinds of hiding places to check
- Verifying Claude's answer instead of taking it on faith

## Hints

- **Hint 1 (free):** Not everything in a document is printed on the page.
