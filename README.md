# Field Agents

A free, hands-on security CTF for learning Claude chat, Claude Code, and the Claude Console.

You're a new recruit at the Directorate. Your partner is an AI agent that wakes up with no memory. Work through spy-themed missions on real security tasks: log triage, phishing analysis, code scanning, remediation, detection engineering, and agent security.

## How it works

- Play at [ctf.fieldagentlabs.com](https://ctf.fieldagentlabs.com): register, read Getting started, and open a mission from Challenges. Briefings, hints, and flag submission are all on the site.
- This repo is the safe house your Codespace is built from: mission data, the graders (`control verify <mission>`), and the dev container. Getting started on the site has the button that opens it.
- Chat missions work on any Claude plan. Claude Code and Console missions need Claude Code access or Console API credits.
